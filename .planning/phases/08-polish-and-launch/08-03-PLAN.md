**1. PageSpeed / Lighthouse audit (SEO-06):**
Run Lighthouse CLI against production build for 3 pages (run each 3 times, take median):
- `npx lighthouse http://localhost:3000/ro --only-categories=performance --output=json --chrome-flags="--headless"`
- `npx lighthouse http://localhost:3000/ro/servicii/google-ads --only-categories=performance --output=json --chrome-flags="--headless"`
- `npx lighthouse http://localhost:3000/ro/contact --only-categories=performance --output=json --chrome-flags="--headless"`

Target: 90+ on mobile for all three. Record scores.

**2. Accessibility audit (CMPL-04):**
Run axe-core against key pages:
- `npx @axe-core/cli http://localhost:3000/ro --exit`
- `npx @axe-core/cli http://localhost:3000/ro/servicii --exit`
- `npx @axe-core/cli http://localhost:3000/ro/contact --exit`

Target: Zero critical or serious violations. Record any violations found.

**3. Security headers (CMPL-05):**
```bash
curl -I http://localhost:3000/ro 2>/dev/null | grep -iE "(strict-transport|x-content-type|x-frame|referrer-policy)"
```
All 4 headers must be present.

**4. 404 page (CMPL-07):**
```bash
curl -s http://localhost:3000/ro/nonexistent-page-test | grep -i "404"
```
Must return branded 404 content.

**5. i18n completeness check (CMPL-04 semantic HTML):**
Compare key counts between ro.json and en.json:
```bash
node -e "const ro = require('./src/messages/ro.json'); const en = require('./src/messages/en.json'); const countKeys = (obj, prefix='') => Object.entries(obj).reduce((acc, [k,v]) => typeof v === 'object' && v !== null ? acc + countKeys(v, prefix+k+'.') : acc + 1, 0); console.log('RO:', countKeys(ro), 'EN:', countKeys(en));"
```

**If any audit fails:** Identify the specific issue, fix it in the relevant files, re-run the failing audit to confirm the fix. Document both the issue and the fix.

**Important:** Run Lighthouse against `npm start` (production build), NOT `npm run dev`. Dev mode gives artificially low scores due to unminified code and React DevTools overhead.
